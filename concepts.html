Important Cloud Terms (5-7 concepts)

  • 1. Virtualization: Running multiple virtual machines on one physical computer.
  • 2. Scalability: Being able to add or remove computing power easily.
  • 3. Multi-Tenancy: Sharing server space with other users securely.
  • 4. Elasticity: Automatically expanding resources when traffic spikes.
  • 5. Latency: Delay in network data transmission time.
  • 6. Uptime: How long a server stays up and running without crashing.
